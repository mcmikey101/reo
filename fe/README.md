# fe — фронтенд

Веб-интерфейс reo: React + TypeScript + Vite. Отвечает Георгий Сорокин.

- Порт dev-сервера: 5173.
- Адрес API — из переменной `VITE_API_URL` (по умолчанию `http://localhost:8000`).
- Фронт обращается только к API бэкенда, к ML-сервису — нет.
- Dockerfile фронтенда лежит в этой папке.

Соглашения — в [../docs/conventions.md](../docs/conventions.md).
