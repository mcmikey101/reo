# reo

Сервис аналитики отзывов клиентов для бизнесов с несколькими точками — сетей кафе, магазинов, клиник.

reo собирает отзывы всех точек с площадок и из CSV и с помощью ML превращает их в понятные показатели и выводы: насколько довольны клиенты, на что жалуются, как меняется ситуация и чего ждать дальше.

## Возможности MVP

- Точки организации и источники отзывов: сбор с площадок и импорт CSV
- Анализ тональности и индекс удовлетворённости 0–100
- Дашборд с выбором точек, источников и периода
- Автоматическое выделение проблем клиентов
- Суммаризация отзывов с цитатами, выгрузка в PDF
- Тренд, сезонность и прогноз индекса
- Просмотр исходных отзывов
- Выгрузка анализа в XLSX

## Как работаем

- Модель — GitHub Flow: `main` всегда рабочий, прямой push в `main` запрещён.
- Ветка на задачу: `<fe/be/ml>/REO-<номер>-<коротко>`, например `be/REO-22-csv-upload`.
- Коммиты с ключом задачи: `REO-22: добавить парсинг CSV`.
- PR в `main` с заголовком `REO-<номер>: …`; описание — что сделано и как проверить. Слияние — squash.
- Обычный порядок: автор проверяет код через Claude, тимлид проверяет PR через Claude и вливает.
- **Временное исключение до 11.11 (E0):** автор сам вливает свой PR после самопроверки через Claude и зелёного CI. Пока CI нет — вместо него автор запускает линтер и тесты локально. Тимлид смотрит влитые PR позже. С 11.11 — обычный порядок.
