# Экраны

Состав экранов, их поведение и состояния для фронтенда и бэкенда. Показатели считаются по [data-rules.md](data-rules.md). Макет: Figma, вариант A «Ясный», десктоп 1440 × 900 и телефон 390 × 844 (ссылка: https://www.figma.com/design/LPssRY1RwJHOI6onqtRKJI/%D0%9E%D1%82%D0%BA%D0%BB%D0%B8%D0%BA-%E2%80%94-%D0%BC%D0%B0%D0%BA%D0%B5%D1%82-A-%C2%AB%D0%AF%D1%81%D0%BD%D1%8B%D0%B9%C2%BB?node-id=1-609&t=QEVY9RxWFlJ6BX4k-1).

Актуально на 10.11.2026. Макет создавался по исходному документу «Основа макетов MVP» и частично устарел — отличия в разделе «Отличия макета от решений» в [decisions.md](decisions.md). Если макет противоречит этому документу, ориентируйтесь на документ и спросите тимлида.

В интерфейсе продукт называется **reo** (в макете осталось «Отклик»).

## Карта экранов

| Код | Экран | Назначение |
|---|---|---|
| A1 | Вход и регистрация | Доступ, создание организации |
| S1 | Область анализа | Выбор точек и источников |
| S2 | Дашборд | Аналитика по выборке |
| S3 | Суммаризация | Выжимка с цитатами, PDF |
| M1 | Точки | Список, добавление, редактирование |
| M2 | Источники | Подключение, импорт CSV, статусы |
| P1 | Настройки | Профиль и организация |
| R1 | Панель отзывов | Отзывы по выбранному элементу, карточка отзыва |

**Навигация.** Боковое меню: S2, S3, S1, M1, M2, P1. После входа — S2. R1 открывается поверх аналитического экрана (на широком десктопе сдвигает его); закрытие возвращает к тому же графику и положению прокрутки. Из R1 доступна суммаризация выбранной выборки.

**Каркас.** Десктоп: шапка 56 px, боковое меню 232 px (сворачивается до 64 px). Телефон: шапка 56 px, нижняя навигация 64 px («Дашборд», «Сводка», «Данные», «Ещё»). Выдвижные панели: настройки 400 px, отзывы 440 px, формы точек и источников 480 px; одна панель за раз.

## A1. Вход и регистрация

- Вход: email, пароль (показать/скрыть), «Войти», переход к регистрации.
- Регистрация: имя, email, пароль, название организации. Организация создаётся при регистрации.
- Email проверяется по формату; пароль — от 8 символов, с буквой и цифрой. Ошибка входа не раскрывает, есть ли такой email.
- Кнопка при отправке показывает загрузку и защищена от повторного нажатия.
- **Нет:** «Забыли пароль?», восстановления, подтверждения email, SSO, двухфакторной авторизации.
- До реального входа (E10) пользователя подставляет заглушка, все запросы фильтруются по организации.

## M1. Точки

- Заголовок «Точки» и число объектов, кнопка «Добавить точку», поиск по названию и адресу. Строка: название, адрес, число подключений, статус данных, меню. Десктоп — таблица, телефон — карточки.
- Поля формы: название (обязательно, до 120 символов), адрес (обязательно, до 250), категория (необязательно, до 60). Форма — панель справа 480 px, на телефоне на весь экран. После создания — уведомление и «Подключить источник».
- Одинаковый адрес допустим; совпадение названия и адреса — предупреждение о возможном дубле.
- Состояния: нет точек («Добавьте первую точку»); поиск ничего не нашёл; ошибка сохранения (введённое остаётся); закрытие несохранённой формы — подтверждение.
- Удаление: простое, с подтверждением. В подтверждении названа точка и сказано, что вместе с ней удалятся её источники и отзывы. Если точка была в текущей выборке, она из неё исключается.

## M2. Источники

- Список связей «точка × источник»: статус, число отзывов, время последнего сбора. Кнопки «Подключить источник» и «Импорт CSV», фильтры по точке и статусу.
- Действия строки: «Собрать сейчас», «Повторить», «Изменить», «Приостановить / Возобновить», «Отключить».
- Подключение по ссылке (панель 480 px): площадка → точка → ссылка на страницу организации → «Проверить» (показаны найденная организация и до трёх отзывов) → «Подключить и собрать». Ошибка содержит причину и действие.
- Импорт CSV: мастер из трёх шагов (загрузка → сопоставление колонок → предпросмотр и подтверждение), правила — в [data-rules.md](data-rules.md#импорт-csv). Доступен с телефона.
- После получения данных обработка запускается автоматически; «Открыть дашборд» доступна сразу и ведёт к прогрессу.

## S1. Область анализа

- Слева поиск и фильтр категории, в центре точки с чекбоксами, справа источники и итог (число точек, источников, ориентировочный объём отзывов).
- «Выбрать все» — три состояния (ничего / часть / все), действует на найденное.
- Источник, не подключённый ни к одной выбранной точке, недоступен; ссылка «Подключить» ведёт в M2.
- Кнопки: «Отменить», «Применить», «Применить и открыть дашборд». Изменения не влияют на аналитику до «Применить». При пустом выборе применение недоступно.
- Выбор новой точки период не сбрасывает; недоступный выбранный тип источника исключается с пояснением.
- Открыто: отдельный экран или панель фильтров на дашборде.

## S2. Дашборд

Порядок блоков: заголовок и контекст → сообщение о качестве данных (если нужно) → пять KPI → главный график → тональность → проблемы клиентов → таблица точек → строка состояния данных.

| Блок | Содержание |
|---|---|
| Заголовок | Точки, источники, период, объём выборки; «Настройки», «Скачать XLSX» |
| KPI | Индекс, число отзывов, доля негатива, средний рейтинг, доля позитива; карточка индекса шире остальных в 1,28 раза |
| Главный график | Линия или столбцы; метрика на выбор: индекс, число отзывов, рейтинг. Разбивка: без, по точкам, по источникам (до 4 цветных серий, остальные — «Остальные»). Тренд, сезонность и прогноз с интервалом; при короткой истории — «Недостаточно данных для прогноза». Оси: индекс 0–100, рейтинг 1–5, количество от нуля |
| Тональность | Доли позитива, негатива, нейтральных по интервалам; рядом число отзывов без определённой тональности |
| Проблемы клиентов | Список групп: название, размер, доля, динамика; переход к отзывам группы; запуск анализа и его статус |
| Таблица точек | Название, индекс, отзывы, позитив %, негатив %, рейтинг; сортировка; строка открывает аналитику точки |
| Строка состояния | Дата обновления, сколько источников работает и сколько с ошибкой, ссылка в M2 |

- Панель настроек (400 px): период, шаг времени, минимальное число отзывов для точки графика (по умолчанию 10). Применяется сразу, без кнопки «Сохранить»; пока данные обновляются, прежние остаются видны. «Сбросить» возвращает 30 дней, неделю и порог 10, не меняя точки и источники.
- Клик по дате или столбцу графика открывает R1 с этим отрезком; KPI позитива и негатива — R1 с фильтром тональности. Клики не меняют общую выборку.
- У каждого графика: заголовок, единица измерения, объём выборки, подписи осей, действие «Показать таблицей». Позитив и негатив обозначены не только цветом (слова, значки). Нет сравнения с прошлым периодом.

## R1. Панель отзывов

- Заголовок: период, точка или группа проблем, число найденных отзывов; активные фильтры видны, локальные изменения общую выборку не меняют.
- Фильтры: все / позитив / негатив / нейтрально; сортировка по дате или рейтингу.
- Карточка отзыва: точка (название, адрес, ссылка на страницу организации), источник (площадка или «Импорт CSV»), дата и оценка (для неизвестных — понятная подпись), полный текст (длинный раскрывается, копируется), тональность и статус анализа, идентификатор на площадке, внутренний ID (копируется отдельно).
- «Открыть оригинал» — в новой вкладке, если есть прямая ссылка; иначе «Открыть страницу организации». Если нет ни ссылки, ни идентификатора, карточка так и говорит и не обещает найти оригинал.
- Внизу списка — «Суммаризировать эту выборку» (ведёт в S3 с теми же параметрами). Кнопок ответа и отметки «Обработан» нет.
- Возврат: из карточки — к списку, закрытие панели — к исходному графику и прокрутке.

## S3. Суммаризация

- Заголовок, параметры выборки, число текстовых отзывов, дата формирования. До первого запуска — объяснение и «Сформировать».
- Результат: общий вывод, «Что нравится» и «На что жалуются» (тезисы, число подтверждающих отзывов, цитаты, переход к отзывам). Десктоп — две колонки; телефон — сначала жалобы, затем плюсы.
- «Обновить» строит новую выжимку; пока она строится, прежняя доступна, повторный запуск заблокирован. При ошибке прежняя сохраняется, есть «Повторить».
- «Скачать PDF» доступна для любой успешно сформированной выжимки.
- Нет текстовых отзывов: «Недостаточно текстовых данных для суммаризации» и действие «Расширить период / изменить источники». Малая выборка показывается с предупреждением об объёме.
- Нет рекомендаций, сравнения с прошлым периодом, истории и расписания.

## P1. Настройки

- Вкладки: «Профиль» (имя редактируется, email показан без изменения) и «Организация» (название, отрасль — необязательное текстовое поле). Выход из аккаунта — через профиль в шапке.
- Десктоп: вкладки слева, форма до 640 px; телефон: список разделов.
- Форма сохраняется кнопкой; выход без сохранения — подтверждение.
- Открыто: что ещё войдёт в P1.

## Состояния

| Ситуация | Что видит пользователь |
|---|---|
| Нет точек | S2 и M1: объяснение и «Добавить точку» |
| Нет источников | «Подключить источник» или «Импорт CSV» |
| Первый сбор | Прогресс по источникам и число полученных отзывов; «Открыть источники» |
| Текст обрабатывается | «Получено N, обработано M»; готовая часть доступна с пометкой неполноты |
| Выборка обновляется | Прежние графики приглушены, тонкий индикатор; блоки не прыгают |
| Нет отзывов за период | Нулевой счётчик, пустой график, действие «Изменить период или источники»; фиктивных точек нет |
| Малая выборка | Предупреждение с n; ненадёжные участки отмечены формой (пунктир) и пояснением |
| Проблемы клиентов не рассчитаны | Пояснение и запуск анализа; при малом объёме данных — отдельное сообщение |
| Устаревший анализ | Пометка и действие «Обновить» |
| Ошибка источника | Плашка: название, дата последнего успеха, «Исправить»; остальные источники работают |
| Ошибка анализа или виджета | Локальное сообщение и «Повторить»; успешные данные не удаляются |
| Суммаризация формируется / готова | Индикатор, прежняя выжимка доступна / текст, цитаты, дата, «Обновить», «Скачать PDF» |
| Ошибка сохранения или выгрузки | Причина и повтор; введённое и готовый результат остаются |
| Успешное действие | Короткое уведомление, состояние отражено и на экране |

Ошибка и пустое состояние различаются текстом, иконкой и действием; цвет — только дополнительный сигнал.

## Телефон

- Рабочие поля 16 px, зона нажатия не меньше 44 × 44 px; проверка также на ширине 360 px.
- S2: KPI каруселью по 1,3 карточки, графики в одну колонку, таблица точек — карточки с раскрытием. Вместо наведения — нажатие: первое показывает подсказку, «Открыть отзывы» выполняет переход.
- M1, M2, S1, R1: формы и панели на весь экран; возврат сохраняет выбор и положение страницы.

## Доступность

Контраст обычного текста не ниже 4,5:1, крупного и графики — 3:1. Видимый фокус клавиатуры. Esc закрывает панель и возвращает фокус на вызвавшую кнопку.
