Подробности — [api-contract.md](api-contract.md) | Один формат для всех экранов; проверка дубля на сервере не зависит от пагинации; фронт верстает M1 целиком, формат не меняется в E2 | Артём |

Подробности — [ml-contract.md](ml-contract.md) | Один битый отзыв не блокирует обработку остальных; ошибки кода клиента видны сразу | Камиль, Михаил, Артём |

Без текста и без оценки — `skipped`, в индекс и знаменатель долей не входит, в числе отзывов учитывается | Доли и индекс дашборда считаются по одному набору отзывов и сходятся с ML | Камиль |

## Отличия макета от решений

Макет создан по исходному документу MVP от 27.10. Реализуем по этому списку, а не по макету:

| В макете / исходном документе | Как реализуем |
|---|---|
| Название «Отклик» | **reo** |
| Ручной список аспектов (вкладка «Аспекты» в P1), пять графиков по каждому аспекту, фрагменты по аспекту, кнопка «Анализировать аспекты» | Нет. Вместо этого автоматические проблемы клиентов на S2 |
| Прогноз и линия тренда вне MVP | Входят: тренд, сезонность и прогноз индекса на главном графике |
| Восстановление пароля, подтверждение email, «Забыли пароль?» | Нет (вход без писем) |
| Условные площадки («Площадка 1», «Площадка 2») | Реальный парсинг первой площадки + CSV |
| Лист «Аспекты» и «Фрагменты» в XLSX | Лист «Проблемы клиентов» |
| Архивация точки, «Показать архивные», «Восстановить» | Простое удаление с подтверждением |
