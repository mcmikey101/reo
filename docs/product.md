# reo — продукт

Что делает reo, для кого и что входит в MVP. Термины — в конце. Правила подсчёта данных — [data-rules.md](data-rules.md), экраны — [screens.md](screens.md), принятые решения — [decisions.md](decisions.md).

Актуально на 10.11.2026.

---

## 1. Суть

**Проблема.** Бизнесы с несколькими точками (сети кафе, магазины, клиники) получают отзывы на многих площадках. Читать их вручную долго, звёзды не объясняют причин недовольства, сравнить точки и увидеть динамику почти невозможно.

**Решение.** reo собирает отзывы всех точек в одном месте и с помощью ML превращает их в показатели и выводы: насколько довольны клиенты, на что жалуются, как меняется ситуация и чего ждать дальше.

**Для кого.** Владельцы и управляющие сетей, маркетологи, специалисты по клиентскому опыту.

**Ключевой принцип — общая выборка.** Точки, источники и период выбираются один раз и действуют на всех аналитических экранах (дашборд, отзывы, суммаризация, выгрузка). Выбор сохраняется при переходах и после обновления страницы. Из любого показателя или графика можно перейти к исходным отзывам.

## 2. Границы MVP

**Входит**
- точки организации; источники отзывов: сбор с площадок по ссылке и импорт CSV;
- тональность отзывов и индекс удовлетворённости 0–100;
- дашборд с выбором точек, источников и периода;
- автоматическое выделение проблем клиентов;
- суммаризация с цитатами, выгрузка в PDF;
- тренд, сезонность и прогноз индекса;
- просмотр исходных отзывов;
- выгрузка анализа в XLSX;
- регистрация с созданием организации, вход по логину и паролю, профиль и организация;
- десктоп (1440) и телефон (390).

**Не входит:** оповещения; ответы на отзывы и отметки обработки; роли и приглашение сотрудников; сравнение с конкурентами; карты; тарифы; автоматические отчёты; сохранённые представления и именованные срезы; письма (подтверждение email, восстановление пароля); SSO и двухфакторная авторизация; ручной список аспектов; история суммаризаций; публичные ссылки.

Если задача требует чего-то из списка «не входит» — это расширение объёма, его согласуют с тимлидом.

## 3. Функциональность

| Блок | Что делает |
|---|---|
| Точки | Пользователь заводит филиалы: название и адрес |
| Источники | К точке подключается страница на площадке (по ссылке) или загружается CSV. Сервис собирает отзывы, убирает дубли, показывает статусы и ошибки |
| Анализ удовлетворённости (ML-1) | Каждый отзыв получает тональность; по выборке считается индекс 0–100 |
| Дашборд | KPI, главный график динамики, распределение тональности, проблемы клиентов, таблица точек — по выбранной выборке |
| Проблемы клиентов (ML-4) | Сервис сам находит группы похожих жалоб, называет их, показывает долю и динамику без ручной настройки |
| Суммаризация (ML-2) | По кнопке — вывод по выборке: что хвалят, на что жалуются, с цитатами. Скачивается в PDF |
| Прогноз и тренды (ML-3) | На главном графике: линия тренда, сезонность, прогноз индекса. При малой истории — «Недостаточно данных для прогноза» |
| Отзывы | Из показателя или графика открываются отзывы, на которых он построен |
| Выгрузка | Анализ по выборке — в XLSX, суммаризация — в PDF |
| Аккаунт | Регистрация, вход, профиль, организация. У каждой организации свои данные |

## 4. Пользовательские пути

1. **От регистрации до первого результата.** Регистрация → пустой дашборд «Добавьте первую точку» → точки (M1) → источник или CSV (M2) → сбор и анализ → дашборд с KPI и графиком.
2. **Проблемы клиентов.** Дашборд → блок «Проблемы клиентов» → список с долями и динамикой → отзывы проблемы (R1).
3. **Проверить основание вывода.** Дашборд → KPI, точка графика или проблема → R1 с отфильтрованными отзывами → карточка → «Открыть оригинал».
4. **Суммаризация.** Дашборд → S3 с той же выборкой → «Сформировать» → вывод и тезисы с цитатами → «Скачать PDF». При смене выборки прежняя выжимка помечается устаревшей.
5. **Динамика и прогноз.** Дашборд → главный график → тренд, сезонность, прогноз.
6. **Выгрузка.** Дашборд → проверить выборку и дату обновления → «Скачать XLSX».
7. **Ошибка источника.** Плашка на дашборде → M2 → исправить ссылку или загрузить CSV заново → повторить сбор → вернуться на дашборд.

На телефоне пути те же; панели открываются на весь экран.

## 5. Как устроена система

```
fe  ──HTTP──▶  api  ──HTTP──▶  ml
                │
                ▼
                db
```

- Фронт обращается только к `api`; `ml` с фронтом и БД не связан.
- ML-сервис без доступа к БД: бэкенд передаёт тексты и сохраняет результаты.
- Все запросы `api` фильтруются по организации текущего пользователя.
- Порты, переменные окружения, `/health` — в [conventions.md](conventions.md).

## 6. Глоссарий

| Термин | Значение |
|---|---|
| **reo** | Название продукта. Старое рабочее название в макетах — «Отклик» |
| **Организация** | Бизнес-клиент (сеть кафе, магазинов, клиник). Данные организации не видны другим |
| **Пользователь** | Сотрудник организации |
| **Точка** | Отдельный филиал: название и адрес |
| **Площадка** | Внешний сервис, где клиенты оставляют отзывы (карты, агрегаторы) |
| **Источник** | Откуда приходят отзывы точки: страница точки на площадке (ссылка) или CSV. У точки может быть несколько источников |
| **Сбор** | Автоматическое получение отзывов со страницы на площадке |
| **Импорт** | Загрузка отзывов из CSV |
| **Отзыв** | Запись клиента: текст (может отсутствовать), оценка в звёздах (может отсутствовать), дата, точка, источник, ссылка на оригинал (если есть) |
| **Дубль** | Повтор одного отзыва в одном источнике; исключается. Дубли между площадками не ищем |
| **Выборка** | Набор «точки × источники × период», общий для всех аналитических экранов |
| **Тональность** | Позитив, негатив или нейтрально; определяет ML-модель |
| **Индекс удовлетворённости** | Показатель отношения клиентов по шкале 0–100 |
| **KPI** | Показатели в верхней части дашборда: индекс, число отзывов, доли позитива и негатива, средний рейтинг |
| **Проблема клиентов** | Автоматически найденная группа похожих жалоб, например «долгое ожидание заказа»: название, размер, доля, динамика |
| **Суммаризация** | Вывод по отзывам выборки: общий вывод, положительные и отрицательные тезисы с цитатами |
| **Цитата** | Дословный фрагмент реального отзыва. Выдуманные цитаты недопустимы |
| **Тренд, сезонность, прогноз** | Направление изменения индекса; повторяющиеся колебания; ожидаемые значения с доверительным интервалом |
| **Устаревший результат** | Результат по другой выборке или до появления новых данных; показывается с явной пометкой |
